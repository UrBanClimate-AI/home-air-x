# AIR-X 홈페이지 (air-x.co.kr)

주식회사 에어엑스 공식 홈페이지. 정적 단일 페이지(`index.html`)이며 GitHub Pages로 배포됩니다.

- 서비스 도메인: https://air-x.co.kr (`CNAME` 파일)
- `air-x.kr` 은 별도 리포지토리 [home-air-x-redirect](https://github.com/UrBanClimate-AI/home-air-x-redirect) 에서 이 도메인으로 리다이렉트됩니다.

## 배포

`main` 브랜치 루트에 푸시하면 GitHub Pages가 그대로 서빙합니다. (Settings → Pages → Source: Deploy from a branch, `main` / `/ (root)`)
